# QJE 2019 — The Effect of Minimum Wages on Low-Wage Jobs

> Cengiz, Dube, Lindner & Zipperer (2019), *Quarterly Journal of Economics* 134(3): 1405–1454. DOI [10.1093/qje/qjz014](https://doi.org/10.1093/qje/qjz014)
> **"The Effect of Minimum Wages on Low-Wage Jobs"**

A reading-and-replication workspace for the paper, built on the official replication package
(Harvard Dataverse **[doi:10.7910/DVN/TJCTC7](https://doi.org/10.7910/DVN/TJCTC7)**), plus a
re-implementation of every main-text table and the headline figures in
[StatsPAI](https://pypi.org/project/statspai/) and a set of modern staggered-DID extensions.

## How to run

1. Download and extract the package: `bash Data/download.sh`, then unzip `data1–3.zip` into `Data/`
   (they contain `data/…`), `dofiles.zip` into `Program/`, and `estimates/figures/tables.zip` into
   `Materials/author_outputs/` (see [Data/README.md](Data/README.md)).
2. Stata 18 MP with `reghdfe`, `ftools`, `estout`, `gtools`, `binscatter`, `tsspell` (SSC),
   `graphexportpdf` (SSC) and `grc1leg` (`net install grc1leg, from(http://www.stata.com/users/vwiggins/)`).
3. Edit `global ROOT` at the top of `Program/run_original.do`, then
   `stata-mp -b do Program/run_original.do` (all exhibits) or pass step names, e.g.
   `stata-mp -b do Program/run_original.do Table1_for_QJE Figure2_for_QJE`.
   By default the wrapper starts from the shipped intermediate datasets (`global BUILDDATA 1` also
   re-runs the data-construction steps, which need CPS-MORG microdata that are **not** in the package).
4. Copy `Materials/author_outputs/estimates/*.ster` into `Results/estimates/` (`cp -n`) before running:
   several do-files (Table 2 cols 1–5, Table 4, appendix tables) `est use` estimates whose regressions
   are commented out in the shipped code.
5. StatsPAI: `cd Program/statspai && python3.13 replicate_table1.py` etc. (see [Program/statspai/README.md](Program/statspai/README.md)).

**Edits to the author's code: none.** All path handling is in `run_original.do`.
